PowerRank — Price Refresh Tool

Internal use only. Not linked from the site, excluded from indexing.
This talks to a Netlify function that writes to Supabase with elevated access, gated by a password only you know. Open each Amazon link yourself, check the current price, update the field, and save — one row or all of them. Use + Add battery, + Add solar panel or + Add bundle for new products, and Details on any row to see and edit every field. You can also fix a product's brand, model, or ASIN (the 10-character Amazon product ID in its link, e.g. B0DG8JQNS4) — edited fields turn orange until saved. Use Delete to permanently remove a product that's no longer available. Click ↗ to load a product in a separate Amazon window; after that, type the price and press Enter to save and move to the next row, which loads in the same window. Saving a price that hasn't changed still refreshes its "checked" timestamp, so it's fine to resave everything even when nothing moved.

Add a battery

Fields marked * are required. Price is only used for scoring and the budget filter — it's never shown on the public site.

Add a solar panel

Fields marked * are required. Use the cheapest configuration on Amazon. Open-circuit voltage (Voc) is needed to match a panel to power stations.

Add a battery + solar bundle

One Amazon listing that sells a power station together with solar panels. The site uses the bundle only when it's cheaper than buying the station and panels separately, and then shows a "Bundle" tag on that pick. Add the station and the panel first if they aren't listed yet.
