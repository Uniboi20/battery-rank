PowerRank — Price Refresh Tool

Internal use only. Not linked from the site, excluded from indexing.
This talks to a Netlify function that writes to Supabase with elevated access, gated by a password only you know. Open each Amazon link yourself, check the current price, update the field, and save — one row or all of them. Saving a price that hasn't changed still refreshes its "checked" timestamp, so it's fine to resave everything even when nothing moved.
